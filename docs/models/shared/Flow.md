# Flow

The provider flow the assessment gates. Absent means signup.

## Example Usage

```java
import org.noresponse.models.shared.Flow;

Flow value = Flow.SIGNUP;
```


## Values

| Name             | Value            |
| ---------------- | ---------------- |
| `SIGNUP`         | signup           |
| `LOGIN`          | login            |
| `RECOVERY`       | recovery         |
| `PROFILE_CHANGE` | profile_change   |

# Provenance

Customer-submitted input. It does not mean the customer or NoResponse verified ownership.

## Example Usage

```java
import org.noresponse.models.shared.Provenance;

Provenance value = Provenance.SUBMITTED;

// Open enum: use .of() to create instances from custom string values
Provenance custom = Provenance.of("custom_value");
```

# NotFoundErrorCode

Machine codes an HTTP 404 answer can carry.

## Example Usage

```java
import org.noresponse.models.shared.NotFoundErrorCode;

NotFoundErrorCode value = NotFoundErrorCode.NOT_FOUND;

// Open enum: use .of() to create instances from custom string values
NotFoundErrorCode custom = NotFoundErrorCode.of("custom_value");
```


## Values

| Name        | Value       |
| ----------- | ----------- |
| `NOT_FOUND` | not_found   |

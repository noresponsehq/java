# AssuranceLevel

Provider or OIDC assurance level, when the customer has mapped one.

## Example Usage

```java
import org.noresponse.models.shared.AssuranceLevel;

AssuranceLevel value = AssuranceLevel.UNKNOWN;
```


## Values

| Name      | Value     |
| --------- | --------- |
| `UNKNOWN` | unknown   |
| `LOW`     | low       |
| `MEDIUM`  | medium    |
| `HIGH`    | high      |

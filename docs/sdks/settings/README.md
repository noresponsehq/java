# Settings

## Overview

### Available Operations

* [get](#get) - Read an environment's settings.
* [update](#update) - Change an environment's settings.

## get

Reads the settings of the signing key's environment: retention in days; per flow (account_creation, login, purchase) the step_up, review and block thresholds, the default depth and the admission; and the sources the environment refuses. A flow without thresholds of its own shows account_creation's with inherits_account_creation true. Requires the management scope; the other environment answers 404 not_found. Read-only and safe to retry.

        }
    }

## update

Changes only what the body names, in one transaction: retention_days, refused_sources, and per flow step_up, review, block (null turns blocking off), default_depth, admission, hold_seconds, on_expiry, or inherits_account_creation to return login or purchase to account_creation's thresholds. After the change each flow keeps 0 < step_up < review <= 100 and block off or review <= block <= 100; a change that breaks it answers 400 naming the flow. A policy change is one new policy_version with the signing key's prefix as updated_by, and every change is recorded in the workspace's audit log with the key as its actor. Requires the management scope; the other environment answers 404 not_found. A change reaches assessments within a minute.

### Example Usage: flows

<!-- UsageSnippet language="java" operationID="updateSettings" method="patch" path="/v1/workspaces/{workspace_id}/settings/{environment}" example="flows" -->
```java
package hello.world;

import java.lang.Exception;
import java.util.List;
import org.noresponse.NoResponse;
import org.noresponse.models.errors.AuthenticationException;
import org.noresponse.models.errors.BadRequestException;
import org.noresponse.models.errors.ConflictException;
import org.noresponse.models.errors.NotFoundException;
import org.noresponse.models.errors.PermissionDeniedException;
import org.noresponse.models.errors.RateLimitException;
import org.noresponse.models.operations.UpdateSettingsResponse;
import org.noresponse.models.shared.Admission;
import org.noresponse.models.shared.DefaultDepth;
import org.noresponse.models.shared.FlowChange;
import org.noresponse.models.shared.KeyEnvironment;
import org.noresponse.models.shared.OnExpiry;
import org.noresponse.models.shared.SettingsRequest;
import org.noresponse.models.shared.SettingsRequestFlows;
import org.noresponse.models.shared.SourceId;

public class Application {

    public static void main(String[] args) throws Exception {

        NoResponse sdk = NoResponse.builder()
                .apiKey(System.getenv().getOrDefault("NORESPONSE_API_KEY", ""))
            .build();

        UpdateSettingsResponse res = sdk.settings().update()
                .workspaceId("tnt_01JA2Z8K6Q4V7W9XBCDEFGHJKM")
                .environment(KeyEnvironment.LIVE)
                .body(SettingsRequest.builder()
                    .retentionDays(90L)
                    .refusedSources(List.of(
                        SourceId.PHONE))
                    .flows(SettingsRequestFlows.builder()
                        .accountCreation(FlowChange.builder()
                            .admission(Admission.HELD)
                            .holdSeconds(600L)
                            .onExpiry(OnExpiry.REVIEW)
                            .build())
                        .login(FlowChange.builder()
                            .stepUp(30L)
                            .review(60L)
                            .block(null)
                            .defaultDepth(DefaultDepth.FULL)
                            .build())
                        .purchase(FlowChange.builder()
                            .inheritsAccountCreation(true)
                            .build())
                        .build())
                    .build())
                .call();

        if (res.settings().isPresent()) {
            System.out.println(res.settings().get());
        }
    }
}
```
